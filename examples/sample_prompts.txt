# Sample Prompts for the text-to-3d-asset pipeline
#
# Prompt pattern that works best downstream (used by the validated locomotive
# run in docs/demo.gif):
#
#   <subject>, single centered object, plain white background,
#   studio product render, <full side view | 3/4 view | isometric view>
#
# Stage 1 does text->image; Hunyuan3D-2 then auto-removes the background, so a
# single clear subject on a plain background is what meshes cleanly.

## Style modifiers (append at your own risk — simple looks mesh best)
- low-poly, game-ready        # cleaner downstream topology expectations
- photorealistic, 8k          # richer albedo, slower to converge visually
- matte clay render           # nice for shape-only (--mode shape) checks
#
# AVOID: "multiple objects", scene descriptions, dramatic fog/backlighting,
# and printed text/logos — they all degrade background removal or bake
# unwanted shapes into the mesh.
